# ميدان — نظام إدارة المندوبين الميدانيين

نظام مركزي يربط المندوبين الميدانيين بإدارة العمل — من بغداد إلى البصرة، كل محل في مكانه الصحيح.

A centralized system that connects field representatives with operations management — from Baghdad to Basra, every shop in its right place. Built for Iraqi field teams who register shops across all 18 governorates.

---

## ✨ المميزات الرئيسية (Key Features)

- **تسجيل فوري للمحلات** — نموذج سريع مصمم للاستخدام من الهاتف أثناء التنقل، مع كشف تلقائي للمحلات المكررة
- **تقارير وتحليلات** — متابعة الأداء حسب المحافظة والنشاط والمندوب، وتصدير فوري إلى Excel وCSV
- **موقع جغرافي دقيق** — تسجيل إحداثيات كل محل وعرضه على خريطة العراق
- **نظام صلاحيات متعدد المستويات** — مدير عام + مدراء بصلاحيات محددة
- **سجل نشاط كامل** — كل عملية مسجلة بالمستخدم والوقت والبيانات المتأثرة
- **يعمل بالكامل محليًا** — كل البيانات تُخزّن في متصفحك (localStorage) — لا يحتاج خادمًا
- **دعم الوضع الليلي** — تلقائي حسب إعدادات النظام أو يدوي بضغطة زر
- **متجاوب مع الجوال** — يعمل بسلاسة على الهاتف واللوحي والحاسوب

## 🚀 الاستخدام (Usage)

افتح الموقع مباشرة في المتصفح — لا حاجة لتثبيت أي شيء. استخدم أحد الحسابات التجريبية:

| الدور | اسم المستخدم | كلمة المرور |
|------|---------------|--------------|
| مدير النظام | `admin` | `admin123` |
| مندوب ميداني | `ahmed` | `rep123` |

الحسابات التجريبية الأخرى: `hussein`, `mortadha`, `omar`, `sajjad` (كلمة المرور: `rep123`).

## 📊 البيانات التجريبية

عند أول فتح، يُنشئ النظام تلقائيًا:
- 6 مندوبين ميدانيين موزّعين على محافظات مختلفة
- 76 محلًا تجاريًا موزّعًا على 18 محافظة عراقية
- 17 نوعًا من الأنشطة التجارية (بقالة، سوبر ماركت، مطاعم، صيدليات، إلخ)
- سجل نشاط كامل لكل العمليات

كل البيانات محلية في متصفحك — يمكنك مسحها من إعدادات المتصفح لإعادة التهيئة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML / CSS / JavaScript** — تطبيق صفحة واحدة (SPA) بدون أي إطار عمل
- **Leaflet.js** — للخرائط التفاعلية (OpenStreetMap)
- **localStorage** — طبقة بيانات علائقية محلية (users, representatives, shops, governorates, cities, types, logs)
- **SHA-256 + Salt** — تشفير كلمات المرور عبر Web Crypto API
- **IBM Plex Sans Arabic** — خط عربي واضح للقراءة

## 📱 التصميم المتجاوب

- **الهاتف (320px+)** — تخطيط عمودي، شريط تنقل سفلي، نوافذ منبثقة بملء الشاشة
- **اللوحي (768px+)** — تخطيط متوازن مع تنقل علوي
- **الحاسوب (1024px+)** — شريط جانبي ثابت، تخطيط متعدد الأعمدة

دعم `safe-area-inset` لجهاز iPhone X+ و`prefers-reduced-motion` للوصول المُحسّن.

---

## 🔒 الأمان

- كلمات المرور مشفّرة بـ SHA-256 مع salt عشوائي لكل مستخدم
- نظام صلاحيات RBAC — لا يمكن لأي مدير منح صلاحية لا يملكها
- المدير العام لا يمكن تعديله أو حذفه
- منع الحذف المرتبط — لا يمكن حذف محافظة/مدينة/نوع بها محلات مسجلة
